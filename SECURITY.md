# Security reports

The project maintainer is [Praneel7015](https://github.com/Praneel7015). Use GitHub private vulnerability reporting when it is available on the repository, or contact the maintainer through an already trusted private channel. Do not post secrets, recordings, exploitable private details or participant information in public issues.

Provide affected version, impact and a synthetic reproduction. Never send API keys or real meeting content. A report should distinguish local capture, provider upload, artifact integrity and desktop configuration. Recording does not trigger Teams' native announcement; participant notice remains required. Source archives and cached artifacts must not silently replace established integrity baselines.

No comprehensive security audit is claimed. Hosted providers have independent retention policies. Installation must not automatically enable recording, uploads, login services or modify system audio configuration.
